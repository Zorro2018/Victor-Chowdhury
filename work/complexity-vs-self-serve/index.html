Self-Serve Rate against Call Complexity, by workflow and over time -- where self-service is winning, and where the residual agent-handled mix is getting harder.

Demo data -- portable snapshot
Portable demo build. This report's live source (an internal reporting platform) is behind Walmart SSO and wasn't accessible for this build, so the structure here was inferred from the report name plus two already-documented, related bodies of work: the Call Complexity Scorecard's six-factor Low/Medium/High scoring model, and the Sierra Voice AI Self-Serve Rate metric. Every workflow name, volume, complexity score, and SSR value below is synthetic (fixed-seed, generated in-browser) -- no real production numbers, and the exact chart set may not match the live report 1:1. Swap in a screenshot or export of the real page any time and this gets tightened up to match.
